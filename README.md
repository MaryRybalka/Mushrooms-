# Mushrooms- / Mushroom Nocturne

Прототип и дизайн-док 2D игры на **Unity/C#**:
мрачная сказка с лавкрафтианским настроением, вдохновленная *The Sinking City*, *Alone in the Dark* и *Hollow Knight*, где все герои — грибы.

## Что уже добавлено
- Полный GDD с кампанией на 4–6 часов, биомами, лором, боем, головоломками и прогрессией.
- Базовые C# скрипты для MVP-систем:
  - простой бой игрока,
  - простейший AI врагов,
  - рунные головоломки,
  - торговля и валюта,
  - костры-сохранения,
  - коллекционные предметы,
  - примитивные достижения,
  - каркас актовой сюжетной кампании.

## Как использовать
1. Создай Unity проект (2022 LTS, 2D URP).
2. Скопируй директорию `Assets/Scripts` в проект.
3. Создай сцены (Hub + биомы) и привяжи скрипты к префабам.
4. Настрой Input, теги (`Player`), коллайдеры и слои врагов.
5. Добавь публичные ассеты из источников, перечисленных в GDD.

## Ассеты
В GDD перечислены допустимые публичные источники (Kenney, OpenGameArt, itch.io free packs), а также вариант с генерацией концепт-арта в сторонних нейросетях.
